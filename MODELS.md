# Модели

## Найденная модель

Во всех 20 файлах семантики указана `qwen/qwen3.8-27b:free`, версия промпта `decompose_v5`. Модель уже использовалась для распознавания ролей слайдов, компонентов и редактируемых слотов.

## Использование в генераторе

Исходная `qwen/qwen3.8-27b:free` доступна через OpenRouter как multimodal-модель с поддержкой structured output и полностью совпадает с моделью, записанной в 20 исходных файлах семантики. Однако её общий бесплатный inference-пул может временно отвечать `429`.

Проверенная бесплатная конфигурация использует `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free` через OpenRouter для текстовой и vision-роли. Модель реально проверена текстовым и multimodal-запросом. Бесплатный endpoint имеет rate limits, поэтому для production рекомендуется платная пара `qwen/qwen3-30b-a3b-instruct-2507` и `qwen/qwen3-vl-32b-instruct`; переключение выполняется только переменными окружения.

Переменные окружения:

- `PRESENTATION_LLM_BASE_URL` - базовый URL API без `/chat/completions`.
- `OPENROUTER_API_KEY` - единый ключ рекомендуемой конфигурации.
- `PRESENTATION_LLM_API_KEY` - необязательная отдельная замена ключа текстовой модели.
- `PRESENTATION_LLM_MODEL` - необязательная замена имени модели.

Промпт хранится в `presentation_builder/prompts/planner_system.txt` и включается в устанавливаемый Python-пакет. Нейросеть не редактирует OpenXML напрямую: она возвращает проверяемый JSON-план.

## Изображения

Текстовая модель не должна выбирать неизвестные изображения только по содержимому файла. Генератор поддерживает два режима:

- готовый `captions.json` с описаниями изображений;
- автоматическое описание через `--vision-model` или `PRESENTATION_VLM_MODEL`.

Для этого слоя подходит `Qwen/Qwen3-VL-32B-Instruct`: это VLM на 32B параметров с Apache 2.0, то есть он укладывается в ограничение ТЗ до 35B. Более старый совместимый вариант — `Qwen/Qwen2.5-VL-32B-Instruct`. VLM только описывает изображения, после чего текстовый планировщик сопоставляет их с темой и слотами. Отправка картинок внешнему API включается только явно.
